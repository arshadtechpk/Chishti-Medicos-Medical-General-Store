Chishti Medical & General Store - Search & Cart Website

Features:
- Searchable medicine/product catalogue
- Click a product to add it to cart
- Quantity +/-
- Customer details
- WhatsApp order with complete cart details
- 18+ Private Care age confirmation
- Home delivery

GitHub Pages:
Upload index.html and style.css to the repository root.
Then Settings > Pages > Deploy from branch > main / root.
